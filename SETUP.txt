ORDER PAD — OWNER SHIFT CORRECTIONS

1. Extract this ZIP. Upload the website files to the published branch/folder of
   your existing GitHub repository avenger545/order-pad, replacing the old files.
   Keep index.html at the top level of the published folder. Do not upload only the ZIP.
2. Firebase > Firestore Database > Rules: replace the entire rules text with the
   included firestore.rules and click Publish. This is REQUIRED for owner-only
   shift corrections. Uploading website files does not update Firebase rules.
3. After GitHub Pages deploys, refresh https://avenger545.github.io/order-pad/.

OWNER: danizghrayzi@gmail.com
- Shifts > Owner: shift corrections > Add missed shift.
- Enter worker name and actual start date/time. Enter end date/time if finished,
  or leave end empty if still working.
- For a forgotten clock-out, use Correct times beside the active shift.
- For an already finished shift, use Shift log > Edit (select All for older shifts).
- Times use the device's local time. Set the tablet's time zone correctly.
- Overlapping shifts, future times and end-before-start are rejected by the form.
- Paid shifts stay locked in the app. Undo the payment before correcting one;
  check the corrected amount before marking it paid again.

THERMAL PRINTING
Settings > Receipt printer: choose 58 mm or 80 mm. Orders > Print receipt.
Select your installed printer, matching paper width, 100% scale and no margins.
Disable browser headers/footers. Printing does not mark an order paid or done.

Code and validation checks are local; live Firebase permissions and your physical
printer need verification after deployment.

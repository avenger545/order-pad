THERMAL PRINTING
Settings > Receipt printer: choose 58 mm or 80 mm. Orders > Print receipt.
Select your installed printer, matching paper width, 100% scale and no margins.
Disable browser headers/footers. Printing does not mark an order paid or done.

Code and validation checks are local; live Firebase permissions and your physical
printer need verification after deployment.

CHANGE LOGIN PASSWORD
After uploading the website files to GitHub, refresh the app and open
Settings > Account > Change password. Enter the current password, a new password
and the same new password again. Choose Save password.
Owner, manager and worker accounts can each change their own password.
This changes the shared login for everyone using that same email account.
No additional Firestore rule changes are needed for this feature.
Passwords are sent to Firebase Authentication; they are not saved in the
app's Firestore database or local storage.

OWNER: LOG OUT EVERYONE AND UPDATE
Publish the included firestore.rules and upload the website files to GitHub.
All devices must load this release once before they can receive logout requests.
For future updates, wait for GitHub Pages deployment to finish, then use
Settings > Account > App updates > Log out everyone and update. Confirm the action.
This signs out the owner too. Unsaved forms/orders may be lost. Saved records stay.
Connected devices sign out and reload. Offline/suspended devices respond when
they reconnect/resume and read the server request. Users then sign in again.
A cache-busting page URL requests the deployed website; ensure deployment is
finished before using this option. Older app versions without the listener need
a manual refresh first. This is app-managed logout, not Firebase Admin token
revocation; it does not remove accounts or change their passwords.

LONGER RECEIPTS AND CUSTOM MESSAGE
Settings > Receipt printer > Receipt spacing: Compact, Roomy, or Extra space.
Roomy is the new default, with more space between items and a bottom paper margin.
Type your message in Message at the bottom of receipts. Enter creates a new line.
The message replaces Thank you!; leave it blank to omit the footer message.
Settings save automatically on this printing device; configure other devices
separately. This affects Order Pad's Print receipt output. Other printing apps
may override the layout. No additional Firestore rules changes are required.

ROOSTER BERG RECEIPT LOGO
Upload ALL files, including receipt-logo.png, to your GitHub Pages folder.
The supplied restaurant image prints centered above the name on receipts.
Settings > Receipt printer > Restaurant logo lets you turn it off or on.
It is enabled by default. Color is converted to grayscale in the print layout.
The original image includes its yellow background; this prints as gray on thermal
paper. Test one receipt to check your printer's darkness and image quality.
Printing waits for the logo to load. No additional Firebase rules are needed.

CHANGE LOGO INSIDE THE APP
Settings > Receipt printer > Choose a new logo. Select PNG, JPG or WebP up to 1 MB.
A preview appears and the logo saves on this browser/device, ready for printing.
The image keeps its proportions and fits both paper widths.
Choose Restore Rooster Berg logo to return to the included image, or No logo
to hide it. Configure each printing device separately. No Firebase rule changes.
